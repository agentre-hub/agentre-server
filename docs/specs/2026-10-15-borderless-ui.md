# 无边框改版（控制台网页端）：外框 + 内容页、去掉结构线

> Status: Approved
> Owner: 控制台前端
> Last updated: 2026-10-15

**Objective:** 控制台（登录后的 `AppShell` 各页）与登录 / 设备授权页在浅色与深色下都不再用线条划分区域：侧边导航、顶栏、移动端底部 Tab 是同一个外框底色，工作区是一张浮起的圆角内容页，页内的卡片、表格、按钮与输入框都靠填充而不靠描边——与桌面端同一套规则、同一份 token。

**Hard invariant:** 本站不新增本地色值或圆角 token（`design-token-contract.test.ts` 继续成立），所有新表面都来自共享包；正文与弱化文字对它落到的每个表面不低于 4.5:1；键盘焦点环不变；复选框、单选按钮、开关保留边；页面结构与路由不变（`?tab=` 等深链接继续可用）；移动端「页面本身不滚动、滚动只在 `main` 里」的外壳约束不变。

**依赖：** 桌面仓规格 `agentre/docs/specs/2026-10-15-borderless-ui.md` 交付并推送后的共享包提交。本文的实现先把 `@agentre-hub/agentre-ui` 的固定提交抬到那个提交，再改本站的外壳与页面。

## Problem

证据来自源码检索与对本地运行实例的整页快照；对照 mockup 与桌面端在同一个评审页（桌面仓 `.dev-kit/artifacts/2026-10-15-borderless-ui/mockups/`，本地证据，不入库）。

1. **外框不是一个表面。** 侧边导航是 `bg-sidebar`，顶栏与移动端底部 Tab 是 `bg-card`；工作区直接露出根节点的 `bg-background`，没有内容页的概念；各页再各自画 `bg-card` 的页头带、`bg-sidebar` 的筛选条。（已验证）
2. **本站自己的线条。** 本站源码约 102 处画边的类，分布在 44 个文件：`border` 53、`border-t` 23、`border-b` 20、`border-r` 3、`border-l` 2；最多的是账户页、新建对话的几个面板、总览页、活动统计、设备页。（已验证）
3. **与桌面端风格分叉。** 桌面端改为无边风格后，共享组件（会话列表、转录、输入框、看板、组织、设置面板、弹层）在本站会变成无边的，而本站外壳与页面仍是带边的，两种风格混在一页上。（推断，依赖桌面端交付）

## Actors and user stories

1. As a `控制台用户`, I want 网页端和桌面端是同一种干净的界面, so that 两边切换不用重新适应。
2. As a `手机上用控制台的用户`, I want 去掉线条后各区域仍分得清, so that 小屏上不会糊成一片。

## Design decisions

| # | Decision | Basis and rejected option |
|---|---|---|
| 1 | 与桌面端同一套「外框 + 内容页」规则与 token；本站不新增色值 | 用户要求 server 一起处理；`design-token-contract.test.ts` 不允许本地色值 |
| 2 | 桌面宽度下：侧边导航与顶栏落在外框色上，工作区是内容页（圆角、与外框之间留缝） | 与桌面端决策 1 一致 |
| 3 | 移动端：顶栏与底部 Tab 在外框色上，内容页铺满宽度、不留缝不圆角 | 小屏上留缝与圆角吃掉可用宽度；外框与内容页之间仍靠色阶区分。Rejected: 与桌面宽度一样留缝——在 375px 宽上浪费 16px 且两侧圆角割裂列表 |
| 4 | 设置页保持路由页（`/settings?tab=…`），只改外观 | 用户确认（2026-10-15）。网页端的设置有 `?tab=` 深链接（用户菜单、外壳、总览都链到它），手机上整页也比对话框好用。Rejected: 与桌面端一样改为对话框 |
| 5 | 登录 / 设备授权页：页面底是外框色，卡片是内容页色、圆角加大、靠阴影立起来，不画边 | 与桌面端的对话框规则一致 |

## 外壳

- **侧边导航（≥ md）：** 外框色，右侧不画线；当前项用抬起色；底部账户区上方的分隔线去掉，用留白分开；折叠把手是填充的小胶囊，不画边。
- **顶栏：** 外框色，不画下边线；不再是 `bg-card`。连接状态小圆点的描边环随之取外框色。
- **工作区：** 内容页色，桌面宽度下圆角 12px、与外框之间留 8px 缝；非 flush 页面的内边距不变；flush 页面（对话、看板、组织）由页面自己在内容页里排布。
- **移动端底部 Tab：** 外框色，不画上边线。

- **页面布局由外壳声明：** 每个控制台页面声明自己是「整页内容页」还是「索引列 + 内容页」（对话、组织）；外壳据此把索引列放在外框上、把详情放在内容页里，页面不再各自给自己的根节点涂底色。（原型只能靠 `:has(...)` 猜，说明现在没有这个钩子。）
- **对话页没有顶栏：** 内容页上沿也要与外框留缝；语言 / 主题按钮不能落进内容页的角上，放在外框上（例如索引列顶部或侧边导航底部）。

## 页面

- **对话：** 会话列表列在外框上（不再覆盖成 `bg-card`），详情是内容页；顶部条带、详情头、文件预览列、输入框区、新建对话的各个面板与选择列表去掉边线，改为留白与填充。
- **看板：** 页头与筛选条不再各自一个色带；任务卡、执行目标胶囊只靠填充。
- **组织：** 索引列在外框上，详情是内容页；详情头、执行目标分组、选择器按钮去掉边线。
- **总览：** 面板、指标块、分段控件、等待中提示条去掉边线改为填充；侧栏分隔线去掉。
- **设备：** 设备行、卡片、添加设备向导的分段页脚、端口转发与升级面板去掉边线；整页不再包在一张卡片里；「命令说明 + 命令代码」是一个填充块（一个组件），不是标签条与代码框两块拼起来。
- **设置：** 外观与桌面端设置对话框的内容区一致（分组是填充块，组内不画线）；活动统计面板的卡片同样处理；「LLM 供应商 / Agent 后端 / 隐私」这排按钮改为分段控件（仍是 `?tab=` 深链接）。
- **总览热力图：** 「没有活动」的格子由脚下表面相对取色，落在填充卡片上两个主题都看得见（现在的 `--heat-0` 假定背后是白色卡片，换成填充后深色下会消失）。
- **账户：** 分节卡片、节头分隔线、行分隔线去掉，分节之间用留白，行之间用行距。
- **登录、设备授权、成功 / 拒绝 / 过期、404 / 即将上线：** 见决策 5；设备码输入框按字段规则（无边填充，聚焦时焦点环）；「或」两侧的分隔线去掉，只留文字。
- **任务详情对话框：** 标题与描述是就地编辑（不加填充）；胶囊分组之间的竖线改为留白。
- **小按钮：** 「授权」、图标块、任务详情里的胶囊等只靠外框才像按钮的控件，改用共享包的有填充样式。
- **空状态：** 虚线框改为填充块。

## 控件与弹层

- 与桌面端规格「控件」「结构线」两节一致：outline 按钮与字段改为相对前景色的填充；页签改为分段控件；弹层与对话框只靠表面色与阴影。这些大多随共享包生效；本站手写的同类写法逐处跟上。

## 文档

- `docs/design.md`：Colour tokens（`chrome` 在本站一直借 `--sidebar` 表达，改为共享包的外框 token）、The auth shell 的卡片描述、The console / The shell 的各带描述、Server console primitives 表中 `MobileTabBar` / `ConsoleNavItem` 的写法，删除与新规则冲突的旧描述。

## Out of scope

- 设置改为对话框（决策 4）。
- 本地运行时发现的两个既有问题，与本文无关、单独跟踪：`vite dev` 下页面空白（`use-sync-external-store/shim` 导出缺失）；新增 LLM 供应商表单写「Base URL 留空走默认」但后端拒绝空值（400 参数错误）。
- 端口转发、设备配对等功能行为；本文只改外观。
- 共享包内的改动——由桌面仓规格负责。

## Testing decisions

| Seam | What it verifies | Prior art |
|---|---|---|
| `src/__tests__/design-token-contract.test.ts`、`eslint-guardrails.test.ts` | 本站仍无本地色值；新外观只用共享包声明的 token；若共享包新增「结构线」lint 规则，本站接入同一条规则并有守卫 | 同文件 |
| 组件 / 页面测试中断言外观类名的用例 | 按新外观改写：`Metric` 不再要求 `border-border`、`InlineEmpty` 不再要求 `border-dashed`、输入框区滚动时不再出现 `border-t`、连接小圆点的环色随顶栏改为外框色 | `console-primitives.test.tsx`、`session-detail.test.tsx`、`user-menu-connection.test.tsx` |
| 布局尺寸断言 | 侧边导航 224 / 56px、底部 Tab 高度、对话页头 68px 等几何不变 | `app-shell.test.tsx`、`mobile-nav-drawer.test.tsx`、`chat-mobile.test.tsx`、`new-conversation.test.tsx` |

不能自动化的部分：浅深两个主题、桌面宽度与手机宽度下各页的观感与「还剩哪些线」——收尾时在本地实例上逐页各拍图并跑边框审计，写进验证报告。
