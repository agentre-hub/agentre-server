# 控制台移动端适配：第一轮（server 宿主侧）

> Status: Approved
> Owner: server 控制台前端
> Last updated: 2026-09-21

**Objective:** 在手机宽度（≤767px，实测 390 与 360）上，控制台宿主自己渲染的每一屏都能完整看到内容、够得着每个操作：组织详情能滚、发送键始终在、会话里打开文件不再压垮整屏、失败有提示、截断的关键信息有地方看全。

**Hard invariant:** 桌面宽度（≥768px）的布局与行为不变；移动端既有的「一次一屏」导航（列表 → 详情 → 返回）、底部 tab、账号菜单入口不回退；`@agentre-hub/agentre-ui` 共享包本轮不改、不重新 pin。

## Problem

证据来自 2026-09-21 的实测：`e2e` 播种账号 + 一台真 agentred 登录到本地 e2e server + 一轮真 Claude Code 对话，用自带触屏 context（390×844 / 360×640，`isMobile`、`hasTouch`、2× 像素比）逐屏驱动，截图与记录在 `e2e/scratch/2026-09-21-mobile-audit/`（本地、gitignored）。代码位置均已核实。

1. **组织页 Agent 详情在手机上滚不动（已验证）。** 移动端 `org-layout` 是纵向 flex，详情列 `Org.tsx:321` 缺 `min-h-0`，于是随内容长高，`OrgAgentDetail.tsx:238` 自己的 `overflow-y-auto` 永远不生效，溢出被 `AppShell` 的 flush `main`（`overflow-hidden`）裁掉。真触屏手势实测：详情滚动容器 `scrollTop` 保持 0，文档整体被推走 289px 后停住——页面顶栏和详情头滚出屏幕、底部 tab 浮到屏幕中部，「执行目标」标题停在 y=850（视口 844），**执行目标与工具区触屏够不着**。部门详情内容短，目前恰好没触发。
2. **发送键被挤出输入框（已验证）。** 会话详情与新对话草稿的输入框底栏里，宿主传入的 `leadingControls` 是 `shrink-0`（`SessionComposer.tsx`），模型 chip 文案长时（如「跟随 Agent 绑定 · CLI 自身登录态」，231px）整排不收缩：390 宽下发送键落在 x=378–410、思考力度 x=370–412，而输入框右沿是 370，两者被裁掉，上下文用量表也看不到。文案短时（「跟随 Agent 绑定」）发送键可见——问题随后端配置出现，不是稳定可见的。
3. **会话里打开文件压垮整屏（已验证，代码）。** 文件预览列固定 420px 且无移动分支（`SessionDetailView.tsx:1864`、`SessionFilePreviewColumn.tsx:111`）：390 屏上转录与输入框被挤成 0 宽，预览列自身溢出约 30px，面板的关闭 × 落在被裁掉的那一条里。
4. **组织页的失败在移动端无声（已验证，代码）。** 保存/删除/执行目标增删的错误提示渲染在索引列底部（`Org.tsx:307-314`），而移动端看详情时索引列不渲染（`Org.tsx:215`），失败时用户看不到任何反馈。
5. **移动端建不了第二个顶层部门（已验证，实测）。** 索引工具栏的「+」只建 Agent；「新建顶层部门」只出现在「一个部门都没有」的空态和桌面端的空详情区（`Org.tsx:424-443`），移动端没有空详情区。建完第一个部门后实测再无入口。
6. **会话详情头部三层、信息缺失（已验证，实测）。** 手机上会话详情依次是：页面顶栏（会话标题单行截断）、机器行（返回 + 机器名 + 在线）、身份行（头像 + Agent 名 + 相对时间 + ⋯），合计约 190px；身份行里 Agent 名与「19分钟前」文字互相压住；360 宽下机器名整个消失；项目名在详情屏任何地方都不出现（`SessionDetailHeader.tsx:214,248` 窄于 420 隐藏项目与机器）。底部 tab 仍常驻，进一步压缩转录区。
7. **设备行（已验证，实测）。** 行首状态点与名字所在的行是 `flex-wrap`（`Devices.tsx:561`），名字一长状态点就独占一行；名字截断，展开详情后仍然看不全；桌面副行「N 个项目 · M 个对话在跑」在移动分支不渲染（`Devices.tsx:703` 仅桌面）。
8. **热力图日值触屏读不到（已验证，实测）。** 单日数值只在鼠标悬停时出现（`Heatmap.tsx:253,290`），实测点格子无任何反馈。
9. **账号页截断（已验证，实测）。** 「邮箱」标签逐字竖排折行、邮箱地址截断无法看全；登录会话的「登录于 · 最后活动 · IP」一行展开后仍截断（`Account.tsx:574`）；通行密钥的创建/最近使用行截断无法展开（`Account.tsx:469`）。

## Actors and user stories

1. 作为在手机上管理组织的用户，我希望 Agent 详情能一路滚到底，改得到执行目标与工具授权；操作失败时当场看到原因；随时能再建一个顶层部门。
2. 作为在手机上和 Agent 对话的用户，我希望发送键始终在手指够得着的地方，头部只占一行却看得到这是哪个 Agent、哪个项目、哪台机器、在不在线，并能点开 Agent 改过的文件看一眼再回来接着聊。
3. 作为在手机上看设备、总览与账号的用户，我希望名字、邮箱、时间这些关键信息有地方看全，点热力图的一天能读到当天的数。

## Design decisions

| # | Decision | Basis and rejected option |
|---|---|---|
| 1 | 本轮只改 `agentre-server` 宿主；共享包里的问题（设置页供应商模型行与模型表、Agent 后端行、任务表单、消息统计行、hover/右键/双击专属操作、选择器里的 Shift+Tab 提示）放第二轮，按「先共享包、再 pin」交付 | 用户决定。本轮问题的根因都在宿主文件里（已逐条核实归属）。Rejected: 本轮跨两仓先修全部 P0——变成成对发布，范围和评审都翻倍 |
| 2 | 移动端在会话里打开文件时，预览以**整屏一层**呈现，覆盖会话与底部 tab | 用户决定。与移动端既有「一次一屏」一致，代码可视行数最多。Rejected: 78% 高的底部弹层——代码行数少一截，与新对话弹层同形态易混，且下拉手势尚不支持 |
| 3 | 移动端会话详情（含新对话草稿）隐藏底部 tab 与页面顶栏，只保留会话自己的一层头部；返回列表后两者恢复 | 用户决定。常见聊天应用形态，为转录与输入框腾出约 190px。Rejected: 保留底部 tab 只合并头部；维持现状只修重叠 |
| 4 | 预览整屏层的「返回」与系统返回手势都只关掉这一层、回到会话，已开的标签保留 | 用户确认。手机上系统返回（Android 返回键、iOS 边缘右滑）是最自然的「退一步」；若它直接离开会话回到列表，用户会在看文件时意外丢掉上下文。Rejected: 不进历史——系统返回会越过预览层直接退出会话 |
| 5 | 组织页「+」在移动端改为两项菜单：新建 Agent / 新建顶层部门；桌面端不变 | 桌面空详情区那两个按钮移动端没有落点；菜单不增加工具栏宽度。Rejected: 在索引底部常驻「新建部门」按钮——与分组内的「新建子部门」混淆，且列表长时被推到很下面 |
| 6 | 组织页错误提示跟着「当前这一屏」：移动端看详情时显示在详情头下方，看索引时维持现有位置 | 提示必须出现在用户正在看的那一屏。Rejected: 改成 toast——会话页等其他宿主没有 toast 体系，另起一套只为这一处 |
| 7 | 输入框底栏收缩顺序：发送键与权限控件永不收缩；模型 chip 先收缩并截断；上下文用量与思考力度在放不下时收成仅图标，但仍可点 | 发送是这一栏的主操作，必须永远在；模型名是最长也最可截断的文案。Rejected: 把控件折到第二行——输入框变高，转录区再被压缩 |
| 8 | 热力图单日读数显示在图下方固定的一行，点一格即更新；未点之前该行提示「点一格看当天」 | 手指会挡住浮层；固定行不遮挡格子。Rejected: 触屏上弹 tooltip——被手指挡住且需要再点别处关闭 |
| 9 | 设备、账号页的截断文字在窄屏改为折行显示，不引入长按/tooltip 查看 | 折行零交互成本，这些值都不长到需要折叠。Rejected: 长按弹出全文——触屏没有发现性 |

## 组织页（移动端）

- **详情可滚动。** 前置：移动端打开任一 Agent 或部门详情。动作：在详情内容区上下滑动。结果：只有详情内容区滚动，页面顶栏、详情头（返回 · 头像 · 名称 · ⋯ · ×）与底部 tab 位置不动；能滚到最后一个区块（执行目标）并完整看到其中的列表与「添加执行目标」按钮。文档本身不产生滚动。
- **失败可见。** 前置：移动端正在看某个详情。动作：删除、保存或增删执行目标失败。结果：与索引页同一文案的错误提示出现在详情头下方；返回索引后提示仍按现有规则显示在索引底部，不重复出现两条。
- **新建顶层部门。** 前置：移动端索引页，已有任意数量的部门。动作：点工具栏「+」。结果：弹出两项菜单「新建 Agent」「新建顶层部门」；前者行为与现在的「+」相同，后者打开与桌面「新建部门」相同的建部门弹层且上级为空。桌面端「+」保持直接新建 Agent。

## 会话详情与新对话草稿（移动端）

- **一层头部。** 前置：移动端打开一条会话或新对话草稿。结果：页面顶栏与底部 tab 不显示；会话自己的头部一行包含：返回（回到对话列表，恢复顶栏与 tab）、会话标题（最多两行，超出省略）、副行「Agent 名 · 项目名 · 机器名」加连接/在线状态、更多操作（⋯）。副行超长时截断，但三个字段都在 DOM 中并可被读屏读到；无项目时省略项目段。草稿没有标题时显示「新对话」，其余字段同上。不再出现文字互相覆盖。
- **状态不丢。** 头部合并后，现有头部承载的信息与操作（在线/离线/连接中状态、更多操作菜单里的每一项）全部保留在这一层，没有任何一项只在桌面才能到达。
- **发送键始终可用。** 前置：360 或 390 宽，任意后端配置（含最长的模型 chip 文案）。结果：发送键与权限控件完整位于输入框内且可点；模型 chip 超长时省略号截断；上下文用量与思考力度放不下时收为仅图标且仍可点开；任何控件都不溢出输入框。桌面端底栏不变。

## 会话中的文件预览（移动端）

- **打开。** 前置：移动端会话详情。动作：点转录里的文件链接（或任何现在会打开预览列的入口）。结果：预览以整屏层覆盖会话（含其头部与输入框），显示现有的预览面板（标签条、文件/改动分段、内容）；顶部有返回，标题为文件名，副行为所在目录与机器名。
- **返回。** 动作：点返回，或系统返回手势。结果：整屏层关闭，回到打开前的会话，转录滚动位置与输入框里未发送的文字不变；已开的标签保留，再点任意文件链接回到这一层并定位到该文件。关掉最后一个标签同样关闭这一层。
- **失败。** 读不到文件（机器离线、文件不存在）时，沿用预览面板现有的失败展示，出现在整屏层内；返回照常可用。
- **桌面端** 仍是会话右侧 420px 定宽列，不变。

## 设备、总览、账号（移动端）

- **设备行。** 状态点始终与设备名在同一行；折叠时名字单行截断，展开后名字完整折行显示；展开后显示与桌面同一文案、同一「数据齐了才显示」规则的「N 个项目 · M 个对话在跑」。
- **热力图。** 图下方固定一行读数。未点任何格子时提示「点一格看当天」；点一格后显示「日期（星期）· N 个对话」，当天为 0 时显示「日期（星期）· 没有对话」；被点的格子有选中描边；今天之后的格子不可点。桌面端悬停行为不变。
- **账号页。** 账号卡的标签与值分两列、值可折行，邮箱完整显示；登录会话的登录时间、最后活动、IP 在窄屏分行显示、不省略；通行密钥的创建与最近使用时间同样折行显示。

## Out of scope

- 共享包侧的全部问题（见决策 1），第二轮单独出 spec。
- 新对话弹层的 Agent 搜索与项目树层级：另一会话正在改 `NewConversationSheet.tsx` / `Chat.tsx`，等其落地后再议。
- 「新建 Agent 后索引列表不刷新、要重载才出现」：尚未与桌面端对比，属于缺陷，走单独的复现与修复，不并入本轮。
- e2e 环境保存 LLM 供应商报「参数错误」：原因未查，不在本轮。
- 真机上的 iOS Safari 软键盘、home 条安全区、横屏：本轮不改；验收时若有真机则一并观察并记录，不作为本轮通过条件。
- 设置页在顶栏下重复一次「设置」大标题：归属待第二轮一并确认。

## Testing decisions

| Seam | What it verifies | Prior art |
|---|---|---|
| 页面级组件测试（Vitest + RTL，`matchMedia` 桩成移动视口） | 组织页「+」菜单两项及其打开的弹层；详情屏上的错误提示；会话详情移动端不渲染页面顶栏与底部 tab、头部含 Agent/项目/机器三段；打开文件后出现整屏层、返回后回到会话且输入框文字仍在；热力图点格子后的读数与 0 值文案；设备展开后的副行；账号页字段完整出现 | `src/__tests__/chat-mobile.test.tsx`（移动形态页面测试）、`Heatmap`/`Devices`/`Account` 现有测试 |
| 布局约束的类名断言 | jsdom 量不了布局，只能锚住成因：移动端详情列带 `min-h-0`、输入框底栏里发送键不收缩而模型 chip 可收缩、设备名那一行不 `flex-wrap` | 同文件里「底部弹层是 flex 列」那条断言的做法 |
| 运行期验证（wrap-up，不入库；用户确认不新增入库的移动端 e2e） | 真触屏手势滚动组织详情到底且文档不滚；390 与 360 宽、最长模型 chip 文案下发送键在框内可点；会话中打开文件 → 返回；系统返回关闭预览层 | 本次审计用的触屏 context 驱动脚本（`e2e/scratch/2026-09-21-mobile-audit/phone.mjs`），配真 agentred |

类名断言只证明「成因被去掉」，证明不了「真的能滚/真的看得见」，后者只由运行期验证覆盖；不新增提交进 smoke 的 e2e 用例。
