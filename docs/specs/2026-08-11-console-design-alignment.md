## 需求

控制台**全部已有页面**的 UI/UX 与 pencil 设计稿逐像素对齐，并落实设计稿里标注的「优化」UX：

1. **外壳**：AppShell 重做 —— 224px SideNav（Brand「AgentRe / 控制台」+ `⌘K` 搜索框 + 4 导航项带
   徽标/元信息/蓝点 + 底部账号区）+ 52px TopBar（页面标题 + 各页注入的计数/新鲜度/按钮）+ 移动端抽屉。
2. **总览（屏 40）**：4 统计卡 + 琥珀色「等你处理」操作条（3 张卡）+ 双栏（左 Agent 卡 + 最近授权与
   变更 | 右 340px 本月用量 + 安全与审计）。
3. **设备（屏 41/44 浅深）**：左设备卡列表 + 右 340px「撤销这台设备」危险卡，展开细节按设计稿。
4. **对话（屏 49b）**：320px 左会话列表列 + 右侧详情区；空态 = 居中详情（图标 + 标题 + 正文 + 主按钮
   + 备选链接）。
5. **会话列表 UX（p5Orc「优化」）**：顶部「最近·跨 Agent」扁平区 + 会话行两行化（第二行带项目·设备
   上下文，无标题会话补上下文标题）+ 筛选 chips（全部/运行中/未读 N）+ `↑↓` 键盘导航 + 选中高亮 +
   行上右键（只放有真实后端的动作）。
6. **design.md**：把控制台契约（外壳、各屏版式、token/字阶、UX 决策）补进 `docs/design.md`。

## 边界

- **诚实空态**：无数据源的区块（用量/配额/审计）渲染真实布局 + 诚实空态，**不编造数字**。
- **不伪造后端**：改名/删除会话等无后端支持的交互一律省略，不得做假按钮/假成功。
- **token 化**：颜色一律走 `globals.css` token，禁字面量；新增 token 过 `design-token-contract.test.ts`。
- **i18n**：所有文案走 `t()`，`en.json` / `zh-CN.json` 双语补齐（`locale-parity` 测试绿）。
- **移动端**：屏 20/29 等移动形态随外壳与列表同步对齐，不退化。
- **DeviceSessions / SessionDetail / ComingSoon / NotFound**：外壳变更的消费方，随外壳与列表组件
  自动对齐，另在 code-review 轴专门核验其正确性（a11y、token、i18n）。
