# 2026-11 控制台手机 PWA 大改版

> Status: Approved
> Owner: agentre-server 维护者
> Last updated: 2026-11-07（基线后澄清：离线首页前提、轮末插话「清掉」范围、提问不停靠、弹层断点；e2e 范围按 e2e 环境能力收窄）

**Objective:** 在手机宽度（≤767px，即现有的 `useIsMobile`）下，把控制台从「桌面页面缩窄 + 底部五个 tab」改成以对话为中心的手机 App：首页是按「需要你 / 进行中 / 今天 / 更早」分段的对话列表，其它页面从左抽屉进入；对话页和新对话页用同一套手机布局（单行页头、底部停靠区、一行统计）；其余页面（登录与设备授权、设备、看板、Agent 与组织、设置、账号、活跃统计）按手机重排成整屏、列表、逐层进入。桌面宽度的界面不变。

**Hard invariants:**
- 桌面宽度（≥768px）的布局、交互与快照不变。共享包的改动只能是新增可选档位（例如触屏档、紧凑档），不传参时行为与今天一致，桌面宿主不受影响。
- 转录内容一律由共享包的真组件渲染（思考、步骤分组、工具卡、失败卡、重试行、统计行、复制），不在宿主另画一份。
- 不加解释性状态横幅；界面不贴机器原话；文案走 i18n，zh-CN 与 en 同步；颜色只用现有 token。
- 不加后端接口、不改 `pkg/wire`、不加迁移。
- 共享包的改动按跨仓顺序先在 agentre 落地（agentre 侧要有对应规格与测试），合并推送后控制台再抬钉接入。

事实标注：**[已核]** 对照 server `73d7adb0` / agentre `be445dee`（共享包钉 `be445dee`）的代码核过；**[已定]** 用户在 2026-11-05～06 的评审中定下（含 2026-11-06 用户同意「按推荐来」的各项）。

## Problem

1. **手机上没有「回到对话」的首页。** [已核] `/` 重定向到 `/overview`（`frontend/src/App.tsx`），手机打开先看到统计页；对话列表沿用桌面的项目树分组，进行中、等你处理的对话混在树里。
2. **底部五个 tab 占屏且平铺。** [已核] `MobileTabBar` 固定显示总览 / 对话 / 看板 / 设备 / 组织，账号、语言、主题挤在每页顶栏；没有「有几条等你」的总入口。
3. **对话页的页头与停止重复、拥挤。** [已核] 手机上页头同时有标题、状态、Agent、机器与「停止」，输入框里也有停止（`useTurnStop` 共享两处）；拇指够不到页头的停止，页头又被挤得截断。
4. **统计行在手机上折成三四行。** [已核] 共享包的 meta 行在 390px 下把 `claude-sonnet-4-5 · ↑52,380 ↓1,630 · 1m 32s · 2.1s · 41 tok/s` 折成多行（`mockups/stats/now-conv-idle-zoom.png`）；没有悬停，token 明细 tooltip 在手机上打不开。
5. **离线横幅看不到。** [已核] 机器离线时横幅在转录顶部，而打开对话默认停在底部，用户看不到为什么发不出去。
6. **其它页面是桌面布局缩窄。** [已核] 设置三个分页（LLM 供应商 / Agent 后端 / 隐私）在 390px 下右侧被截出视口；看板四列横向滚动、手机上拖不动；任务表单是居中小弹窗；设备卡原地展开、添加设备引导插在列表上方要滚两屏；登录与设备授权是居中卡片，主按钮在中段；账号页登录记录显示原始 User-Agent（`Account.tsx`，决策 7），手机上读不懂；登录页没勾同意时按钮置灰、不说原因。
7. **触屏细节。** [已核] 回车在所有设备上都是发送，手机键盘没有 Shift+回车，打不出换行；运行中有草稿时停止与发送挨着且发出后停止会滑到拇指下；排队条上「撤回到输入框」与「删除」两颗按钮各 20px、间隔 2px；审批卡在触屏上显示 ↵ / Esc 键帽；对话通道在切回前台时不主动重连；从对话返回列表时滚动位置丢失。

## Actors and user stories

1. 作为在手机上用主屏幕 App 的用户，我打开 App 就看到哪些对话在等我、哪些在跑，点进去就能处理。
2. 作为在通勤中盯着 Agent 干活的用户，我能在对话页一手完成「看进度 → 插一句 → 停下 → 审批」，按钮都在拇指区，不会误停。
3. 作为在小屏手机上的用户，每一轮的模型和 token 数始终一行看得到，需要时点开看全。

## 外壳与导航

- **落点。** 手机宽度访问 `/` 时进入对话列表（`/chat`）；桌面宽度仍进 `/overview`。PWA 的 `start_url` 保持 `/`。
- **左抽屉取代底部 tab。** 手机宽度下所有页面不再显示 `MobileTabBar`。顶层页面（对话列表、看板、Agent 与组织、设备、活跃统计、设置、账号）页头左侧是 ☰，点开从左侧滑出抽屉（宽 84%、最宽 320px，遮罩可点关，220ms ease-out，尊重「减弱动态效果」）。抽屉自上而下：账号区（头像、名字、邮箱，点进账号页）→ 主导航：对话（带「需要你」条数角标，0 时不显示）、看板、Agent 与组织、设备（带「在线 / 总数」）→「更多」：活跃统计、设置 → 底部：主题、语言。当前页在抽屉里高亮。
- **非顶层页面**（对话、新对话、Agent 详情等）页头左侧是返回键，不显示 ☰。每一层都有看得见的返回，不依赖系统侧滑。
- **通用页头与整屏页。** 顶层页面的页头是「☰ · 标题（可带副行）· 页面动作（＋ / ⋯，≥44px）」；逐层进入的页面是「‹ · 标题 · 动作」，编辑类整屏页是「✕ · 标题 · 保存」。主操作钉在底部安全区之上。每页顶栏里的主题与语言控件移到抽屉底部（设置里也各有一行）。底部弹层统一用共享包 `DialogShell`，沿用它现在的断点（<640px 为底部弹层，640–767px 为居中弹窗）。
- **前台恢复。** [已定] App 切回前台（`visibilitychange` 变为可见或 `pageshow`）时，对话通道立即重连并补齐，不等退避；重连期间页头副标题写「正在连接」，不加横幅。

## 首页（对话列表）

- **页头。** 「☰ · 范围名 ⌄（下面一行副标题）· ⌕ · ✎」。副标题是状态位：全部范围写「N / M 台机器在线」；选了 Agent 或机器时写它的在线状态；本次打开后列表已经载入过、手机随后断网时，换成灰点「没有网络 · HH:MM 的内容」，已载入的列表照常可读，不加横幅。冷启动时就没有网络，沿用现有的离线页（`sw.js` 不缓存 `/v1/`，本轮不改）。
- **筛选胶囊。** 全部 / 需要你 / 进行中 / 未读，单选；数字只在大于 0 时出现；视觉 32px、命中区 44px。「未读」用现有的唯一未读判据，不另写。
- **分段。** 按 需要你（`waiting_for_input`）→ 进行中（运行中且不在等你）→ 今天 → 更早，空段不显示；段内按最后消息时间倒序。
- **行。** 44px Agent 头像；第一行标题 + 行尾时间；第二行「Agent · 项目路径」+ 状态牌（等你 / 运行中 / 出错）或未读点；行高 ≥ 64px；按下有按压态。行的呈现件归共享包（作为现有索引行的新档位，桌面不用），宿主只喂数据。
- **范围弹层。** 点标题弹出底部弹层，三档分段 项目 / Agent / 机器，带搜索与置顶「全部对话」。项目是可折叠树；Agent 按部门分组，带头像、在线点和所在机器；机器分在线 / 离线两段。每项带对话数，有事等你的项旁边一个琥珀点；离线的不隐藏、半透明。选中即换整页范围并关闭弹层。今天的「按机器分组」并入这里。
- **搜索。** ⌕ 把页头换成输入框 + 取消，写明在哪个范围里搜、命中几条，命中字高亮。
- **长按。** 长按一行，行浮起高亮，菜单四项：停止这一轮（仅运行中且可停时）、只看这个 Agent、只看这台机器、删除。每一项在别处都有看得见的入口（对话页停止、范围弹层、对话页 ⋯）。
- **空态。** 主按钮「新对话」撑满宽；有在线设备时附链接「按机器看设备上的对话」（切到机器范围）；没有设备时出口为「添加设备」。
- **返回恢复。** [已定] 从对话返回列表时，恢复同一范围下的滚动位置与筛选。

## 新对话

- 点 ✎ 从底部弹出「选 Agent」：最近 / 可以开 / 现在开不了 三段（判据与顺序用共享包 `groupAgentsForPicking`），每个 Agent 带头像、在线点和机器；开不了的不隐藏、不可点，写明原因；底部「从项目里挑一个 Agent ›」。
- 选定后进入新对话页，布局与对话页相同：页头是收件人（返回 · 头像 · 名字 ⌄ / 在线状态）；正文是空态（头像 + 一句话 + 项目、运行在、模型三行可点的事实 + 接着最近的对话）；底部是同一个输入框。有字时键盘顶起，空态收成只剩三行事实，发出前仍看得到会在哪台机器、哪个项目里跑。发出后原地变成对话页，不换布局。

## 对话页

- **页头。** 一行：返回 · 标题 · ⋯；标题下副标题「● 状态 · Agent · 机器」。状态写字：运行中 / 正在停止 / 等你审批 / 出错 / 空闲 / 离线 · 时间 / 正在连接。页头不放停止。⋯ 打开底部弹层「对话信息」：项目、运行在、模型、最后活动四行，动作「复制对话号」。
- **用户气泡** 右对齐（共享包消息行新增对齐选项，桌面不传时不变）；转录行全部是共享包真组件（`Transcript` 现有渲染）。
- **底部停靠区**，同一位置按状态换内容：
  - 空闲 / 运行中：输入框。空时是胶囊（＋ · 占位字 · 提交位），有字时是卡片（正文在上；下面是 ＋、运行参数胶囊、上下文环、提交位）。运行中且无字：提交位是 ■；运行中有字：■ 与 ↑ 并排，间距 8px，各 44px 命中区；发出插话后 ■ 原地、↑ 置灰，两格位置不动。正在停止：■ 转圈禁用，直到这一轮结束（沿用 `useTurnStop`）。
  - 等你审批：审批停靠在输入框的位置，「允许」整宽，「本会话始终允许」与「拒绝」并排，底部「■ 停止」；转录里不再出内联审批卡；不显示 ↵ / Esc 键帽。Agent 的提问（多选 / 填空）照现在留在转录里作答，不停靠。
  - 机器离线：只读带「{机器} 回来后可以继续发消息 · 查看设备」，历史照常可读；转录顶部不再有离线横幅。
- **排队与放回。** 排队条用共享包 `QueuedMessagesBar` 真件（撤回到输入框 / 删除 / 清空）；触屏下撤回与删除各 44px 命中区、间距 8px；撤回因「正在编辑」不可用时，原因写在条里，不只放在 title。轮末没送到的插话不再挂「恢复为草稿 / 丢弃」条，而是按现有「恢复为草稿」的规则自动接在输入框草稿后面（空行分隔，不覆盖草稿），上方一行「N 条插话没送到，已放回输入框 · 清掉」：「清掉」只移除这次放回的那段文字；用户一旦改动输入框，这行说明消失，不再提供「清掉」。
- **待处理药丸。** 往回翻时，下面有未决审批 / 提问，浮在输入框上方显示「↓ N 项待处理」（计数用 `countPendingBelow`）；没有待处理时是普通的回到底部。
- **触屏输入。** 触屏设备上回车插入换行，只有按钮发送；输入框设 `enterKeyHint`；输入法组词中的回车照旧不触发任何动作。所有输入框字号不低于 16px。触屏上不显示快捷键提示（停止键说明不写「(Esc)」）；有物理键盘时 Esc 停止照旧。
- **键盘。** iOS 主屏幕 App 里键盘升起时，输入框与 @ / / 弹层顶在键盘正上方，不被遮挡。[未知] iOS 是否已经被挡、要改宿主外壳还是共享弹层，在实现第一步用真机确认；无论哪种，结果都必须满足这一条。

### 统计行（每一轮回复底下那一行）

[已定] 手机宽度下统计行只占一行，内容为「模型 · ↑发送 ↓接收 · 用时 · tok/s」+ 行尾复制图标（44px 命中区）；首 token 只在明细里出现。规则：

1. 数字缩写：≥1000 写 k、≥1,000,000 写 M，一位小数（↑52.4k、↑1.3M）；用时写成 `1m32s` / `12m05s` / `49s`。
2. 模型名先规整：去掉厂商前缀（`anthropic/`、`claude-` 等）和末尾日期后缀（`-20250805`）。规整不算「藏」。
3. 放不下时按顺序让：先藏 tok/s，再藏用时，最后才截模型名（省略号，至少露 6 个字符）。是否放得下按实际渲染宽度判，不按字数估；宽度变化（转屏、字体载入）和运行中每次刷新都重新判。
4. ↑↓ 与复制图标永远不藏。
5. 藏了或截了任何东西，行尾出「›」。
6. 点这一行（复制图标除外）打开底部弹层「这一轮」：模型（完整 id）、发送、接收、缓存命中、首 token、耗时、输出速度，数字完整不缩写。运行中那一轮同样适用，数字随刷新更新。

参考结果：390px 常规一轮全露；375px 下长模型名百万 token 那一轮藏 tok/s；320px 下再藏用时；只有规整后仍很长的自定义模型名（如 `deepseek-reasoner-v3.2-exp-thinking`）才会被截断。这一档归共享包的 meta 行（新增紧凑档），桌面不传时不变。

## 登录与设备授权

- **登录。** 整屏、无卡片：品牌与一句标语在上，同意勾选与「使用 GitHub 登录」「通行密钥」两颗按钮钉在拇指区，页脚四个链接去掉（条款与隐私仍在同意那句话里可点）。没勾同意就点登录：不发起登录，勾选框高亮并在旁边写「先勾选同意」（决策 14）。
- **带设备码登录。** 同一副骨架，眉题「设备授权 · {码}」取代码卡，正文一句「登录后继续授权这台设备」。
- **授权确认。** 页头「✕ · 授权设备」，内容依次为 账号行（将接入 {账号} · 换个账号）、风险句、设备卡、核对码；「允许」「拒绝」钉底。
- **授权成功。** 一屏：紧凑步骤条 01✓ 02✓ 03 → 标题 → 一句正文 → 一张命令卡（命令沿用现有来源）；「完成，去设备页」钉底；不再列查看状态、重启两张卡和设备卡。
- **已拒绝。** 图标 + 标题 + 一句说明；「输入新的代码」与「前往控制台」钉底。

## 设备

- **列表。** 一行一台，按在线 / 离线分组，状态写成字（「在线 · 版本 · 可以升级」/「Agentre 没有运行 · 几小时前」）；「添加设备」在页头 ＋。
- **详情。** 点一行进入独立详情页（替代原地展开）：可以升级时顶部一行动作；下面分组列出这台机器上的对话、能跑的 Agent、项目；端口转发取不到时用失败行「什么没成 · 原因 + 重试 / 复制诊断信息」（沿用 `describeFailure`）。
- **添加设备。** 整屏三步（安装并登录 → 输入设备码 → 常驻后台，沿用现有三步与文案），每屏：进度条、标题 + 一句、选项 chips（设备类型、系统）、一张命令卡、「发到电脑上」，下一步钉底。「发到电脑上」调用系统分享，浏览器不支持分享时不显示，命令卡自带复制。

## 看板

- **阶段。** 四列横滚换成顶部四个阶段（待办 / 进行中 / 待审 / 已完成，带条数）一次看一个；卡片满宽；项目范围进标题，「新建任务」进页头 ＋；搜索常驻，其余筛选收进底部弹层（四组条件用 chips，底部按钮写出会看到几条）。
- **移动。** 手机上不拖拽：长按卡片或点卡片上的 ⋯ 弹出「移动到」，四个阶段直接列出，编辑 / 删除在下一组。
- **任务详情。** 沿用现在的任务表单结构（面包屑、大标题、描述、一排 pill：阶段 / 项目 / 标签 / Agent / 执行目标 / 模型）。居中小弹窗改成整屏：保存与 ⋯ 进页头，底部「取消 / 保存」去掉；标题与描述放大占满主区；pill 行像输入框工具栏一样贴底，可折两行，每颗命中区 44px；描述获得焦点、键盘升起时 pill 行停在键盘正上方。关闭时的未保存处理与现在的弹窗一致。

## Agent 与组织

- **索引。** 按部门分组的列表；组头的 Lead 徽标、＋、⋮ 收成「N 人 ›」；每个 Agent 第二行写出在哪台机器、哪个后端上跑；不能对话的带待配置点，原因写在第二行（沿用 `orgNeedsSetupReasons`）；筛选是 chips。
- **Agent 详情。** 页头「‹ · 名字 · ⋯」，保存状态进副行；顺序为 身份 → 系统提示词 → 在哪儿跑（拖把手排序）→ 工具。

## 设置

- **一级列表。** 三个分页改成分组列表：LLM 供应商、Agent 后端、隐私，外观、语言各一行；点进去是独立页面。
- **供应商详情。** 连接信息一项一行加「测试连接」；模型一行一个、开关在右（替代最小 560px 宽的表格）。
- **编辑后端。** 整屏编辑器，按 基本 / 运行方式 / 高级 分组；设备显示备注名。

## 账号与安全

- 分组列表：个人资料、通行密钥、登录记录；「登出其它全部」进登录记录组头；退出登录放到页底。
- 登录记录每条显示「设备 · 浏览器」+ 相对时间 + IP，当前这条标「这台」；点开看原始 User-Agent 与完整时间（决策 13）。

## 活跃统计

- 时间范围切换进标题副行；四格摘要里「对话」「设备在线」可点（分别去对话列表与设备页）；热力图并进一张分组卡，选中一格直接写出当天条数；下面接 Agent 使用排行。

## Out of scope

- 发送前压缩图片、HEIC 处理、拖放附件。
- 侧滑返回、下拉刷新、列表左滑手势。
- 推送通知、离线可写、service worker 缓存策略变更（`sw.js` 保持现状）。
