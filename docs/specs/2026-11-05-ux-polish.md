# 2026-11 控制台 UI/UX 打磨

> Status: Approved
> Owner: agentre-server 维护者
> Last updated: 2026-11-05

**Objective:** 落地 2026-11-05 UI/UX 审查中 Web 控制台的 8 条发现（W1–W8）。每条的问题、代码证据与「现状 / 建议」mockup 见审查页 `/Users/codfrm/Code/agentre/ux-review/server-console.html#fN`（仓库外，未提交；本轮 `.dev-kit/artifacts/2026-11-05-ux-polish/` 下有副本）。本文件只记录**已定的需求与决策**；mockup 与本文冲突时以本文为准。

**Hard invariants:**
- 不加解释性状态 banner；不贴机器原话（原文只进「复制诊断信息」或折叠详情）；引导只给「步骤条 + 标题 + 一句正文 + 命令卡」。
- 只改控制台宿主与 agentre-server 后端；不改 `@agentre-hub/agentre-ui` 钉、不改 `pkg/wire`，不加迁移。
- 每条行为改动先写失败测试（TDD）；`zh-CN` 与 `en` 文案同步。

## Requirements

**W1 添加设备引导批准后给出第 3 步**（高）
- `AddDeviceGuide` 跳转 `/device` 时带 router state `{from: 'add-guide', method}`，`Device.tsx` 透传到成功页。
- `DeviceSuccess` 对 agentred：就地显示步骤条（01✓ 02✓ 03）+ 标题 + 一句正文 + 命令卡；有 method 时按引导所选方式出命令（native → `agentred service install --start`；docker → `docker compose up -d`），无 method（CLI 直接打开）时默认 native 命令 + 共享包已有的安装说明链接。主按钮「完成，去设备页」。不再说「可以关闭这个页面」。组合共享包已导出的 `GuideStepRail` / `AgentredServiceSection` / `CommandCard` / `AgentredInstallDocsLink`，命令字符串复用已有来源不另写。
- 桌面端 kind 的成功页维持现状。

**W2 登录页从 next 里认出设备码**（高）
- `Login.tsx` 抽 `userCodeFromNext(next)`：仅接受本站相对路径，pathname 为 `/device` 时取 `user_code` 并过 `parseUserCode`；与顶层 `user_code` 等价使用。眉题标出「设备授权」。
- 测试：`?next=%2Fdevice%3Fuser_code%3DA4F-7Q2` 显示设备上下文条；外站 next 不认。

**W3 授权确认屏写明哪台机器接入哪个账号**（中）
- 后端 `DevicePendingResponse` / `PendingInfo` 增加 `name`（已存的 hostname，空串时前端回退为类型名，不编造）。
- `DeviceApproval`：设备块标题用主机名，类型降为 chip，图标走 `DEVICE_KIND_ICONS`（不再写死 Laptop）；风险句上方一行「将接入 {显示名} · {邮箱}」+「换个账号」（登出后回到带原 user_code 的登录页）。`DeviceSuccess` 同样用主机名与正确图标。

**W4 登录失败保留两条登录路径**（中）
- 失败只多一个错误框，下方仍是完整的 GitHub 按钮（图标 + 「使用 GitHub 登录」）与通行密钥按钮；设备上下文条保留。未收录的 err 码不显示原码，显示「登录未完成」+「这次登录没有完成，请再试一次。」。删除不再使用的 `login.retryLogin`。

**W5 错误文案分类**（中）
- 宿主 `lib/` 新增 `describeFailure(err, context)`：按离线/断网、对端拒绝、版本过旧、权限、未知分类，返回中文事实句与出口（重试 / 去设备页 / 无）；原文不进可见文案，提供「复制诊断信息」。
- 接入：`DraftSession`（含「无法加载你的设备列表」的错误兜底分支）、`DevicePortForward`、`useBoard`（看板红带补「重试」）、`Device`、各 loadError 调用方。已知业务码走前端 i18n，不再直接显示 `ApiError.message`（英文界面不再出现中文 msg）。
- 决策：不为分类改 `pkg/wire`；无法分类的归 unknown。

**W6 拒绝页给出真出口**（中）
- `DeviceDenied`：一句正文「这台设备不会接入你的账号。如果是误点，回到设备上重新发起授权。」+ 主按钮「输入新的代码」（`/device`）+ 文字链接「前往控制台」；删除 `window.close()` 按钮，保持中性色。

**W7 移动端避让 safe-area 与触屏目标**（中）
- FAB 与 toast mobileOffset 改用与 `MobileTabBar` 共用的常量表达式（74px + 16px + `env(safe-area-inset-bottom)`），不再写死。
- 顶栏控件视觉尺寸不变，命中区扩到 44×44（宿主侧包裹，不改共享包 ThemeToggle）。

**W8 对话空态页内切机器轴**（低）
- 「去设备页找更多对话」改为页内动作「按机器看设备上的对话」（`setAxis("machine")`），仅在有在线设备时出现；无设备时出口为「添加设备」。复用外壳已取的设备列表。

## Out of scope

- agentred RPC 错误的结构化码（需成对改 wire）。
