# 2026-11 控制台手机 PWA：体验整体修整（本地优先、交互、弱网、视觉）

> Status: Draft
> Owner: agentre-server 维护者
> Last updated: 2026-11-26（A1 修订：「按机器」轴不落本地；不变量注明发送去首尾空白照旧）

**Objective:** 手机上把控制台当主屏幕 App 用时：一打开就有上次的内容、网络差也不白屏不被踢走、写下的东西不会丢、返回键行为可预期、每个操作都有明确反馈、失败说得清楚能恢复，并把审计列出的视觉与触控问题一并收掉。

**Hard invariants:**
- **不改动用户发送的任何内容。** 文字与图片原样保存、原样发送，不压缩、不转码、不裁剪。[已定] 2026-11-25发送前去掉首尾空白是现有、与桌面端共用的行为，保留不变，不算改动内容。[已定] 2026-11-26
- **不会把一条消息发两次。** 本地恢复的消息只在「确定还没离开手机」时自动发出；没有确认没送出去的，不自动重发。
- **只有 401 才算登出。** 网络错误、超时、5xx、门户页都不算；登出、401、换账号后，本机不留上一个账号的任何业务数据。
- **不改 `pkg/wire` 与中继协议、不加迁移。** 后端只允许改静态资源的压缩方式（决策 B4）。
- **共享包改动按跨仓顺序**（`../AGENTS.md`「Cross-repository change order」）：先在 agentre 写测试与实现、桌面端验证、推送，本仓再钉新版本。共享包新增的行为一律经可选入参或触屏档位打开，**不传参时桌面端行为与外观不变**。
- **桌面宽度（≥768px）布局不变。** 本文写明「两端一致」的状态与连接 / 数据层改动除外。
- 文案走 i18n，zh-CN 与 en 同步；颜色只用现有 token；触屏可点区域不小于 44px。

事实标注：**[已核]** 对照 server `98bf70fd`（共享包钉 agentre `6af00ccd`）的代码核过；**[已测]** 2026-11-24 审计实测（真 App + 假 `/v1`，Chromium 390×844 触屏，弱网用生产构建 + 限速）；**[审计]** 审计 agent 读代码得出、未逐条复核；**[已定]** 用户 2026-11-24～25 评审定下（「全按推荐」：每张对比稿取提案 B，单方案稿照做，「不出稿、按方向直接做」清单全做）。

## Problem

1. **每次打开都从零联网。** [已核] 没有任何业务数据落在手机上（列表范围缓存、名单、转录、发送队列都只在内存）。[已测] 慢 3G 冷启动 14.4 秒纯白，「加载中…」只停半秒又白到约 22 秒，23 秒出列表；lie-fi 白屏超过 120 秒；导航遇 502 显示裸错误页；入口 JS 652 KB gzip，线上只给 gzip。
2. **网络一抖就被踢回登录页（P0）。** [已测] `/v1/auth/me` 任何失败都跳登录页（断网 0.3 秒即跳），网络恢复后也回不来。[已核] `RequireAuth` 不分错误类型；`useMe` 在 5 处各自请求。
3. **写下的东西会丢（P0）。** [已测] 排队中的消息离开对话就消失；对话草稿、新对话草稿（含「换一个 Agent」）、看板任务编辑、Agent 系统提示词（只在失焦时保存）离开即丢。
4. **执行端连不上时只有「正在连接」（P0）。** [已测] 首次拨号失败后连接其实已恢复，但对话通道不再打开，页面永远「正在连接」，只能整页刷新；首次取票一次 502 就进终态不再重试；连不上没有上限、没有「立即重试」，首页看不出连接状态。[审计] 死连接要等每个请求 30 秒超时才察觉、换连接取票期间仍自称已连接、补齐失败后「在跑」永不消失等。
5. **返回键不可预期。** [已测] 系统返回跳过所有浮层直接离开页面（已安装且无历史时退出 App）；新对话步骤、看板任务页没有历史项；Agent 详情 ‹ 是 push。
6. **操作没有反馈或说法不对。** [已测] 连接中点审批三键灰 30 秒无提示；删除失败对话框停着不说话；长按「停止这一轮」后无任何反馈；退出登录不确认；写操作超时显示英文原文且重点会重复创建；审批超时提示「什么都没发出去」并不属实。
7. **读失败的呈现各页不一致且会误导。** [已测] 对话页里设备名单超时整页换成红框、吞掉转录；供应商加载失败同时出现「还没有配置任何供应商」；`/devices` 无重试；重试键 24px；名单未到时首页写「0 / 0 台机器在线」；502 HTML 被当 JSON 解析出原文报错。
8. **对话页与输入的问题。** [已测] 表格被挤成一字一行；模型选择是桌面浮层且一打开就弹键盘；提问卡显示 `user_ask`、按钮 32px；复制提示盖住输入框；长草稿把转录挤到 140px；大图在弱上行必超时且无进度。
9. **触控与视觉。** [已测] 菜单行 32px、长按菜单盖住行；按钮按下无反馈；多处控件小于 44px、12px 输入框触发 iOS 放大；首次使用无设备时主按钮走不通；组织页两个「Claude Code」；看板编号每次加载都变；条款页回不去；无标题对话显示「— · claudecode · 空闲」；离线提示重复且时间打架；总览热力格 13px；设备授权页是桌面卡片；若干行话与开发者参数。

## Actors and user stories

1. 作为在地铁里打开主屏幕 App 的用户，我想立刻看到上次的列表和对话，新内容到了自己替换上来，而不是对着白屏或登录页。
2. 作为写到一半被打断的用户，我想回来时草稿还在、排队的消息还在并会自己发出去。
3. 作为用手势或系统返回键的用户，我想返回先关掉眼前的浮层，而不是整页离开或退出 App。
4. 作为点了按钮的用户，我想马上知道它在处理、成功了、失败了还是不确定，以及下一步能做什么。
5. 作为执行端暂时连不上的用户，我想被明确告知、能立即重试，并在网络回来后自动恢复。
6. 作为手机借给别人或换账号的用户，我想退出登录后手机上不留我的对话。

## 打开 App 与身份（A、B）

- **有本地数据**：点图标 → 启动壳 → 应用起来后立即画出上次的列表（A1、A5），后台核对身份、拉列表与名单，到了就地替换。
- **核对身份 401**：清空本地（A2）→ 登录页 → 登录后回到原来要去的地方。
- **核对身份失败（网络 / 超时 / 5xx / 门户页）**：继续用本地数据，「网络不稳定」细条，退避重试（A3）。
- **没有本地身份且取不到**：整屏「连不上服务器」，自动重试，取到即进入。
- **完全离线打开**：外壳与数据都从本地来，列表上方沿用「没有网络 · HH:MM 的内容」，时间取这份本地数据的时间。
- **对话**：最近打开的 30 条从本地立即显示内容，页头状态置灰「同步中」，补齐后按序号合并、不重复不跳号；本地内容停在待审批卡上时，审批停靠条先置灰写「正在确认是否还在等你」，确认仍在等才可点，不再等则收起（真手机布局中停靠条占输入框位置，二者不同屏；参考稿 d9 B 帧 2 把两者画在一起，以本文为准）。超过 30 条按最近打开淘汰。
- **新版本**：启动后与回到前台时检查；提示条与重新加载见 B1；重新加载后草稿与未发出的消息原样恢复。

## 草稿与未发出的消息（C）

- 列表行副行优先级：「待发送：<首行>」>「[草稿] <首行>」（红色前缀）> 现状内容。
- 排队规则沿用 2026-11-20 决策 6（每条对话只排一条，新的一条来时旧的交给失败气泡）；「撤销」放回输入框。
- 失败气泡保留「重发 / 复制文本 / 丢弃」，离开与重启后仍在。
- 大图上传见 C4：进度环随实际已发送字节推进；不提供「取消」。
- 排队消息的「撤销」把整条消息（文字与图片，内容不变）放回输入框。

## 返回与导航（D）

- 规则一句话：**系统返回 = 关掉最上层的浮层；没有浮层时 = 页头 ‹ 做的那件事。**
- 有未保存改动的整屏编辑页，返回与 ✕ 走 F4 的确认。
- 已安装 App 无历史时，从深链打开的页面按 ‹ 以替换方式回到上级，不会退出 App（沿用现有对话页规则，推广到所有子页）。

## 执行端连接（E）

- 「正在连接」→ 约 20 秒后「连不上 · 立即重试」+ 倒计时；点「立即重试」立即重拨并重置倒计时。
- 首页页头副行在连接不上时写「执行端连不上」，保留机器在线数。
- 网络恢复（`online`）、回到前台时立即重试（沿用 2026-11-20 回前台规则）。
- 会话已登出（401）时显示「账号已登出 · 重新登录」，不再重拨。

## 操作反馈与确认（F）、读失败（G）

见对应决策。所有「重试」「重新登录」「刷新看看」按钮 44px；同一件事的提示不叠加；提示不遮挡输入框与底部操作区。

## 对话页、触控与各页（H、I、J）

见对应决策。所有新增的触屏行为在共享包里经触屏档位或可选入参打开，桌面端不变。

## Out of scope

- 需要改协议或执行端的：派发幂等（W11 的重试不重复部分）、插话带编号（W17）、协议级心跳、客户端消息号与自动重发。另开一轮。
- 首屏拆包（入口包体积）。另开一轮。
- 已有对话在输入框收起时直接改模型（I27，2026-11-05 决策 5 的既定取舍）。
- 状态栏颜色跟随应用内主题（K1）、iOS 键盘收起后视口不复原（K2）、Web Push / 角标、侧滑返回手势、下拉刷新。
- 桌面宽度的任何布局改动。
